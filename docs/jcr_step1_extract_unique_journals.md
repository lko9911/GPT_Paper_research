# JCR Step 1: Extract Unique Journals

## Purpose

This step creates a local journal candidate table from the existing paper
database. The output is intended for a later manual match against a Journal
Citation Reports CSV export.

This step does not scrape Web of Science, Journal Citation Reports, Clarivate,
Crossref, OpenAlex, publisher pages, or any external service. It only reads
local paper metadata already present in the repository.

## Default Input

The default input is:

```bash
data/papers.json
```

This is the current source-of-truth active paper database. The website uses a
smaller `data/papers_index.json` for startup loading, but that index omits ISSN
fields, so it is not suitable for JCR preparation.

The script can also read CSV input.

## How To Run

Default:

```bash
python scripts/extract_unique_journals.py
```

With explicit paths:

```bash
python scripts/extract_unique_journals.py \
  --input data/papers.json \
  --output data/private/journals_to_match_jcr.csv
```

The JSON output is generated by default at:

```bash
data/private/journals_to_match_jcr.json
```

Pass `--json-output ""` to skip JSON output.

## Outputs

Private outputs:

- `data/private/journals_to_match_jcr.csv`
- `data/private/journals_to_match_jcr.json`

These files are ignored by Git and should not be committed unless explicitly
requested.

## Columns

- `journal_id`: stable local key based on ISSN when available, otherwise a hash of the normalized journal name.
- `journal_original`: most frequent or cleanest original journal title observed in the paper data.
- `journal_normalized`: normalized journal title used for name-based grouping.
- `issn`: normalized print/general ISSN when available.
- `eissn`: normalized electronic ISSN when available.
- `all_issns`: all ISSN-like values observed for the journal group.
- `paper_count`: number of papers mapped to the journal group.
- `example_doi`: example DOI from the group.
- `example_title`: example paper title from the group.
- `example_year`: example publication year from the group.
- `source_fields`: metadata fields that provided the journal name.
- `manual_review_required`: `true` when the journal candidate needs human review.
- `review_note`: reason for manual review.

## Normalization

Journal names are lowercased, whitespace-normalized, stripped of trailing
punctuation, and normalized so `&` and `and` can be compared carefully. The
original journal title is preserved separately.

ISSNs are accepted with or without hyphens and normalized to `XXXX-XXXX` when
valid.

## Manual Review Flags

The script marks `manual_review_required=true` when:

- journal name is missing
- ISSN/eISSN is missing
- multiple different journal names share one ISSN group
- the venue appears to be a repository, preprint archive, conference, thesis, or non-journal source
- the normalized journal name is too short or ambiguous

## Important Boundary

This is only Step 1. It does not perform JCR matching and does not infer JIF,
quartile, impact factor, or journal rank.
